# Project446 Fixer

**Project446 Fixer** — небольшая Windows-утилита для исправления распространённых проблем в **Project446**.

Программа предоставляет простой GUI: выберите проблему, которую хотите исправить, и следуйте подсказкам на экране.

> **Windows only.**
> Для работы требуются права администратора. Если программа запущена без них, она автоматически запросит повышение прав.

## Возможности

### 🔄 Игра не обновляется

Исправляет проблемы, из-за которых Project446 не может нормально установить обновление.

Программа автоматически загружает необходимые файлы, проверяет их целостность и выполняет необходимые действия для восстановления обновления.

### 🖼️ Сломаны иконки инвентаря

Восстанавливает файлы иконок инвентаря.

Перед удалением повреждённых файлов программа создаёт резервную копию, поэтому их можно сохранить на случай непредвиденной ситуации.

### 🌐 Бесконечное «Подключение к сети Project446…»

Выполняет необходимые сетевые настройки для решения проблем с подключением к инфраструктуре Project446.

Программа также покажет дополнительную инструкцию, если потребуется выполнить ещё какие-либо действия.

### ⚠️ Кикает с сервера с `File mismatch`

Помогает восстановить повреждённые или несовпадающие файлы игры.

Steam при этом не закрывается — закрывается только Project446, после чего запускается проверка файлов игры и выполняются дополнительные действия для восстановления.

### 💬 Поддержка

Открывает бота поддержки, где можно получить дополнительную помощь.

### ❌ Выход

Закрывает программу.

## Как пользоваться

1. Запустите `project446-fixer.exe`.
2. При необходимости разрешите запуск от имени администратора.
3. Укажите папку Project446, если программа не смогла найти её автоматически.
4. Выберите проблему, которую хотите исправить.
5. Следуйте инструкциям, появляющимся в окне программы.
6. Дождитесь завершения операции.

Для некоторых исправлений программа может попросить вас подтвердить продолжение. Это нормально — просто следуйте подсказкам.

## Резервные копии

Программа старается создавать резервные копии файлов перед их удалением или заменой.

Например, резервные копии файлов инвентаря сохраняются в папке:

```text
backups\
```

Это позволяет восстановить исходные файлы вручную, если это потребуется.

## Логи

Если исправление не помогло или возникла ошибка, проверьте лог:

```text
logs\fixer.log
```

Лог находится рядом с исполняемым файлом программы.

### Сборка

Обычная сборка:

```bash
cargo build --release
```

Также можно использовать:

```text
build.bat
```

`build.bat` поддерживает `sccache` и дополнительные параметры сборки.

| Переменная    | Значение | Описание                             |
| ------------- | -------- | ------------------------------------ |
| `FAST=1`      | любое    | Использует быстрый профиль сборки    |
| `LOCKED=0`    | `0`      | Отключает `--locked`                 |
| `SCCACHE_DIR` | путь     | Изменяет расположение кеша `sccache` |

После обычной сборки исполняемый файл находится здесь:

```text
target\release\project446-fixer.exe
```

При использовании `build.bat` он также копируется в:

```text
release\.super duper mega fixer 3000 gui.exe
```

## Ресурсы

Рядом с `.exe` должны находиться:

```text
resources\
├── hosts
└── zaprettt\
    └── service.bat
```

`resources\hosts` используется для сетевого исправления, а `service.bat` — для дополнительной настройки подключения.

Для проверки подписей обновлений может использоваться один из следующих файлов:

```text
public_key.bin
public_key.txt
gc_pubkey.txt
csgo_gc.pub
```

Также ключ может быть передан через:

```text
EMBEDDED_PUBKEY_B64
```

## Безопасность обновлений

Обновления проверяются перед установкой:

* проверяется размер файла;
* проверяется SHA-256;
* проверяется Ed25519-подпись, если доступен публичный ключ;
* манифест должен содержать необходимые поля;
* повреждённый или некорректный манифест отклоняется.

Распаковщик `.gcup` также защищён от выхода за пределы директории назначения через абсолютные пути и ...

## Отмена операций

Длительные операции можно отменить непосредственно из GUI.

Отмена поддерживается во время:

* скачивания;
* удаления большого количества файлов;
* распаковки обновления.

При закрытии окна во время выполнения операции программа также старается корректно остановить текущую задачу.

## Системные требования реализации

Проект написан на **Rust** с использованием:

* `egui` / `eframe` — графический интерфейс;
* `ed25519-dalek` — проверка подписей;
* `tracing` — логирование.

Точка входа, повышение привилегий, работа с Windows, DNS, Defender, `hosts`, реестром и системными процессами реализованы отдельно от основной логики.
